A computer vision project that demonstrates 15 essential image processing operations on single and multiple images using OpenCV and Python.
Built using Python with OpenCV (cv2), NumPy, and Google Colab with cv2_imshow for display
Loaded and processed both single images and a batch of 5 images using a loop-based pipeline
Applied grayscale conversion, resizing to 300x300, and cropping (200x200 region) on all images
Performed geometric transformations including 45-degree rotation and horizontal flipping
Applied binary thresholding and histogram equalization for contrast and brightness enhancement
Used Gaussian Blur (5x5 kernel) for noise reduction and smoothing across all images
Implemented Canny Edge Detection to extract sharp edges from grayscale images
Applied morphological operations — Dilation and Erosion — using a 3x3 kernel on binary images
Converted images to HSV color space and added random Gaussian noise for augmentation
Useful as a foundational reference for computer vision preprocessing and image transformation techniques.
